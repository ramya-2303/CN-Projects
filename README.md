# CN Projects

A collection of Computer Networks mini projects implemented using Python, socket programming, SSL/TLS, and SDN concepts.

---

## Projects

### Remote Device Control System
A secure SSL/TLS-based IoT communication system supporting multiple client devices and real-time command handling.

### SDN Flow Analyzer
An SDN mini project using the POX controller and OpenFlow to monitor and analyze network flow statistics.

---

## Technologies Used

- Python
- Socket Programming
- SSL/TLS
- SDN
- OpenFlow
- POX Controller
- Mininet
- WSL
